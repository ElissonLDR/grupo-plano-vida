# Grupo Plano Vida

Crie uma landing page, precisa ser com boa UX/UI, não quero seções com cores diferentes, apenas conteudos quem forem destaques para o objetivo da landing page dentro de conteiners com cor diferente que não ocupam largura completa.

Use as cores:
- Em toda a página use FFF3D7 para o fundo das seções;
- Use #162E27 para background de conteiners com cores escuras, e para títulos que ficam em seções com bg claro;
- Use C07934 para detalhes, ou palavras chaves;
- Use a fonte Montserrat em negrito para títulos, e open sans para textos;
- textos no máximo 16px, frases ou palavras chaves em negrito;
- Use um arredondamento menor nos cards, conteiners, botões;
- Use o simbolo da marca nos cantos das seções com cores escuras de forma discreta, com bem opaca, de modo que fique metade do simbolo visivel, e metade para fora do conteiner não visivel;
- Não gere imagens, use as que eu enviar;

Tom: acolhimento, não peso. Evitar imagem muito pesada de cemitério etc.
